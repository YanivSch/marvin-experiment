# הניסוי של מרווין

הפעלה כיתתית שמשחזרת בקטן את המאמר
Bansal et al., "Does the Whole Exceed its Parts? The Effect of AI Explanations on Complementary Team Performance", CHI 2021.

## מה יש כאן

- `index.html` – ההפעלה כולה בקובץ אחד, בלי תלות בשרת.

## איך זה עובד

1. כל סטודנט מסווג 4 ביקורות לבד ואז 10 ביקורות עם "מרווין", עוזר AI שטועה בכוונה ב-3 מתוך 10.
2. כל סטודנט משובץ באקראי לאחת משלוש קבוצות: ביטחון בלבד, הסבר להמלצה, הסבר אדפטיבי.
3. בסיום מתקבל קוד תוצאה (למשל `MRV-E-3-8-6-2`).
4. במסך "לוח כיתה למרצה" (`#class`) מדביקים את כל הקודים ומקבלים את התמונה הכיתתית.

הביקורות נכתבו במיוחד להפעלה ואינן לקוחות מהמאמר.
